# 🛠️ DIY bitcoin workshops

Hands on guides from the workshops we run. Use them to follow along, or to
run the same workshop yourself.

## 🗝️ Main activity

- [SeedKeeper quiz](games/): attendees unlock a
  SeedKeeper javacard with the SeedKeeper phone app in a proof of work
  game to win a device or a javacard.

## ➕ Optional activities

Before the SeedKeeper quiz, groups can race each other. The winning
group(s) then play the SeedKeeper quiz to see who in each group wins the
device.
[Details](games/)

- 💻 **Laptop, smartcard reader and javacard per group:** the first group
  to flash the Satochip-DIY applet and set it up in Sparrow wins, then
  plays the SeedKeeper quiz.
- 🔋 **Powerbank and signer per group:** any signer that loads 12 seed
  words and takes a passphrase. The first group to load the seed, type
  the riddle's answer as the passphrase and read back the right
  fingerprint wins, then plays the SeedKeeper quiz.
